Khusus pengurus

Ruang Pengurus HVC

Masuk melalui aplikasi Google Apps Script menggunakan PIN rahasia. PIN diperiksa pada server, bukan di GitHub Pages.

  • Buat dan unduh surat Google Docs/PDF
  • Kelola arsip surat masuk dan keluar
  • Edit nomor, tanggal, dan pengaturan surat

🔐 Situs GitHub Pages bersifat publik. Tautan aplikasi bisa dibuka siapa saja, tetapi tindakan administrasi memerlukan PIN aktif dan sesi yang diperiksa Google Apps Script. Jangan memasukkan PIN ke GitHub atau membagikan spreadsheet kepada publik.

Fitur Sistem

Satu aplikasi untuk kebutuhan surat pengurus

Fitur di bawah ini tersedia pada aplikasi Google Apps Script yang terhubung, bukan diproses langsung oleh GitHub Pages.

🔢Penomoran otomatis

Nomor surat disusun otomatis dan dapat dikoreksi pada arsip jika salah.

📆Edit tanggal surat

Tanggal surat masuk dan keluar dapat ditetapkan serta diperbaiki.

📑Google Docs + PDF

Surat dibuat melalui template dan hasilnya disimpan ke Google Drive.

✍️TTD Ketua Umum

Satu tanda tangan Ketua Umum berada di tengah pada surat yang diterbitkan.

🗂️Arsip terorganisir

Surat masuk dan keluar tersimpan terpisah dengan fitur pencarian.

🖼️Template kertas A4

Identitas HVC serta ornamen pada format surat A4.

Panduan Singkat

Cara menggunakan aplikasi

Langkah pengurus dari membuka portal hingga mendapatkan surat PDF.

  1. 1
    Klik Buka AplikasiAnda akan diarahkan ke web aplikasi Google Apps Script HVC.
  2. 2
    Masukkan PIN pengurusPIN 8–16 digit yang sudah ditetapkan pengelola pada Google Apps Script. Tidak memerlukan email pengurus.
  3. 3
    Pilih jenis surat dan isi dataSesuaikan tanggal, nomor otomatis, dan informasi anggota.
  4. 4
    Buat Docs dan PDFHasil surat dapat dibuka dan dicari kembali melalui menu Arsip.
Informasi untuk pengurus

Website GitHub ini merupakan halaman depan. Pengolahan surat dan arsip tidak dilakukan pada halaman publik.

  • Data surat berada di Google Sheets dan Drive milik pengurus.
  • Akses pembuatan surat dan arsip dilindungi PIN dan sesi pada Google Apps Script.
  • Jika tombol Buka Aplikasi belum aktif, administrator perlu mengisi URL Apps Script pada file config.js.

Administrasi HVC yang lebih tertata.
